# Data

Place the organiser-provided trips here (not included in the zip to keep it small):

```
data/raw/train/<trip_id>/<trip_id>.track|.nodes|.arcs|.route         (80 trips)
data/raw/student_test/<trip_id>/<trip_id>.track|.nodes|.arcs|.route  (10 trips)
```

`data/processed/` is generated by `scripts/02_build_dataset.py`.
Evaluator-testing trips are never stored in this repository. Point the API at them with `PATHSNAP_EVAL_DIR`.
